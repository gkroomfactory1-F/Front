☁️ ตั้งค่าใช้งานออนไลน์ (ข้อมูลซิงค์ทุกเครื่อง)

ขั้นตอนตั้งค่า (ทำครั้งเดียว ใช้เวลา ~5 นาที ฟรี):

  1. เข้า console.firebase.google.com ล็อกอินด้วย Gmail แล้วกด "Add project" ตั้งชื่ออะไรก็ได้ เช่น gekko-pipe-system
  2. ในโปรเจกต์ ไปที่เมนู Build → Firestore Database กด "Create database" เลือกโหมด Production mode แล้วเลือก location ใกล้ๆ (เช่น asia-southeast1)
  3. ไปที่แท็บ Rules ของ Firestore แล้ววางกฎนี้ทับของเดิม จากนั้นกด Publish: 
    rules_version = '2';
service cloud.firestore {
  match /databases/{db}/documents {
    match /{document=**} {
      allow read, write: if request.auth != null;
    }
  }
}
  4. ไปที่เมนู Build → Authentication กด "Get started" แล้วเปิดใช้งานผู้ให้บริการ Anonymous (ให้เข้าแอปได้โดยไม่ต้องมีบัญชี/รหัสผ่าน)
  5. กลับไปหน้าโปรเจกต์หลัก (รูปเฟือง ⚙️ ข้าง Project Overview → Project settings) เลื่อนลงมาที่ "Your apps" กด ไอคอนเว็บ </> เพื่อสร้างเว็บแอป ตั้งชื่ออะไรก็ได้ แล้วกด Register app
  6. จะมีโค้ด const firebaseConfig = { ... } ขึ้นมา — คัดลอกทั้งก้อนตั้งแต่ { ถึง } มาวางในช่องด้านล่างนี้

⚠️ ทุกเครื่อง/ทุกคนที่เปิดลิงก์แอปนี้ (พร้อมตั้งค่า config เดียวกัน) จะเห็นและแก้ไขข้อมูลชุดเดียวกันแบบเรียลไทม์ — อย่าแชร์ลิงก์แอปหรือ config นี้ให้คนนอกทีม
